# blogkhamim.my.id

Source code for my personal blog at [blogkhamim.my.id](https://blogkhamim.my.id).

## Tech Stack

- [Astro](https://astro.build) for static site generation
- [Tailwind CSS](https://tailwindcss.com) for styling
- Markdown / MDX for posts
- React for a few interactive parts (search, comments)
- GitHub Pages + GitHub Actions for hosting and deployment

## Running Locally

```bash
npm install
npm run dev
```

Then open http://localhost:4321. Run `npm run build` to create a production build in `dist/`.
